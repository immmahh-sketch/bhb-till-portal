Carvery check printer

Black Horse Beamish, for the tills

Install on this till

Prints the carvery checks (bar, kitchen, pass and guest copy), or the Black Horse Botanicals receipts, on the receipt printer next to this till. No administrator password needed.

Download the installer

Then

  1. Open the downloaded file (Chrome shows it at the bottom or top right, or in the Downloads folder). Right-click it, choose Extract All, then open the folder it makes.
  2. Double-click install.cmd. If Windows says it protected your PC, click More info, then Run anyway.
  3. Type the number of the receipt printer by this till. If it is not in the list, type C (the printer is on a serial cable).
  4. Say what this till prints: 1 Bar check (drinks), 2 Kitchen check (food), 3 Pass check (food), 4 Guest copy (the VAT receipt for the customer), 5 Black Horse Botanicals receipts. For example 1, or 2,3. On the Botanicals till choose only 5.
  5. Say whether this printer is the Main one (M) or the Backup (B). A backup only prints a check if the main printer has not printed it within 45 seconds: no power, lost connection, paper being changed, cover open, or the till switched off. Backup checks say BACKUP PRINT at the top.
  6. A TEST check prints. Answer Y if it came out clearly.
Already installed on this till? Download update-now.cmd and double-click it (if Chrome blocks it, click the arrow beside the warning and choose Keep). It fetches the latest program itself and restarts it, and keeps your settings. Then check the log: the line "printer program started" should say version 2026-11-07.
It starts by itself whenever this user signs in, so there is nothing to open on a Sunday. To remove it, run uninstall.cmd from the folder C:\Users\(name)\AppData\Local\BHB Carvery Printer.
