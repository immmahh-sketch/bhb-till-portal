Carvery check printer for a till
================================
1. Right-click this zip file and choose "Extract All", then open the folder it makes.
2. Double-click  install.cmd
   (If Windows says it protected your PC, click "More info", then "Run anyway".)
3. Answer the questions on the screen:
     - which printer is next to this till (type its number)
     - which checks this till prints: 1 = Bar (drinks), 2 = Kitchen (food), 3 = Pass (food). Type 1, or 2,3, and so on.
4. A TEST check prints. Say Y if it came out clearly.
That is all. No administrator password is needed, and it starts by itself whenever this user signs in.

To take it off this till again: double-click uninstall.cmd (in the folder C:\Users\<name>\AppData\Local\BHB Carvery Printer).
